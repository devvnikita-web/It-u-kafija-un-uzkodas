# Itāļu kafija un uzkodas

Лендинг итальянской кофейни в Старой Риге (Torņa iela 4).

Статический сайт: `index.html`, `css/style.css`, `js/main.js`. Никакой сборки не требуется — просто открыть `index.html` в браузере или раздать через любой статический сервер.

- Заказ доставки: [Bolt Food](https://food.bolt.eu/en/3/p/986-italu-kafija-un-uzkodas)
- Карта и адрес — раздел "Как найти" (интерактивная карта Google Maps)
